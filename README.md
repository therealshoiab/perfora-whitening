# Perfora Purple Whitening Store 🍇✨

A high-converting, mobile-first e-commerce landing page for **Perfora Purple Whitening Toothpaste** and oral care products.

## 🚀 Live Demo
**Live Website**: [https://therealshoiab.github.io/perfora-whitening/](https://therealshoiab.github.io/perfora-whitening/)

## 🌟 Key Features
- **Mobile-First Responsive Design**: Optimized for seamless browsing across smartphones, tablets, and desktops.
- **Interactive Product Showcase & Modal Views**: Fast image gallery, product details, usage guides, and customer reviews.
- **Cart & WhatsApp Checkout System**: Direct-to-WhatsApp ordering with order ID generation, full customer address capture, and UPI payment workflow.
- **Zero-Dependency Lightweight Build**: Pure HTML5, CSS3, and modern vanilla JavaScript with embedded assets for blazing-fast load times.
